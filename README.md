# personal-voice

一份写给 AI 看的中文文风规范。约 1900 字，十条变换，十个可数参数。

## 这是什么

人写中文有一个稳定的分布：句子长短不齐，逗号推进，专名和数字密集，口语连接词多，结尾不升华。模型写中文也有一个分布：句长齐整，形容词多，结尾总想升华。

这份文件把前一个分布压成可执行的规则，用来给生成的文字做校准和自检。

## 里面有什么

- 参数表：句号密度、逗号密度、平均句长、句长标准差、段长、段落长短差、专名密度、口语连接词、形容词配额、感叹号
- 事实优先三条：评价跟事实、归因落到人、数字带口径
- 十条变换：删元话语、还原名词化、抽象落地、情绪直给、删软化词、长句合并、重复推进、括号私货、结尾降调、改错字留口语
- 语体配额：书面连接词和口语连接词分开计数，报告腔可以当骨架但要落地
- 红线与排版：鸡汤结尾、夸张形容词、引号堆砌
- 边界：引文代码不动，不确定不抹平，单次命中不算证据

## 怎么用

把 `SKILL.md` 放进支持技能加载的目录，或者直接粘进系统提示。写完一段中文，按第七节自检八条过一遍。

也可以当检查表用：数句长标准差，数专名，找元话语，看结尾。

## 数据从哪来

参数是从三篇亲笔全文里量出来的，样本量小，每个文体只有一篇。逗号密度这类数字只能当参考，不能当铁律。文中标了"需要现场判断"的地方就是这种情况。

## 不适合谁

写公文、论文、英文，或者写给客户的商务邮件。这套规则是个人文风，不是通用写作规范。
